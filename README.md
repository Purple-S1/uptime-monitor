# Uptime Monitor 📡

Gevorderd project (VS09) voor het keuzedeel *Verdieping software* van Sven Teuben.

Een monitoringapplicatie die elke 30 seconden controleert of een aantal websites bereikbaar is en hoe snel ze reageren. De resultaten worden opgeslagen in een database en getoond in een Grafana-dashboard en op een eenvoudige statuspagina.

Het project draait volledig in Docker-containers die samenwerken via Docker Compose.

> Dit project is nog in opbouw. Elk onderdeel wordt in een eigen branch gebouwd en via een pull request toegevoegd.
